# 河谷小镇 — 类星露谷物语

2D 俯视角像素种田/生活模拟。当前产物是**一个可自由走动、房子都能进的河边小镇**，加上一套可玩的**种田循环**：开荒 → 播种 → 浇水 → 过夜生长 → 收获 → 卖钱。

所有美术资源都是**运行时程序化生成**的（`src/art/` 里用代码画像素），仓库中没有任何图片文件。整套素材约 1 秒烘焙完成。

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 类型检查 + 打包到 dist/
```

## 美术风格规则

素材是代码生成的，但遵守的是手绘像素画的规矩。这几条写在 `src/art/palette.ts` 和 `src/art/pixel.ts` 里，是整套素材能"看起来像一个人画的"的原因：

**1. 色相偏移（hue shifting）。** 阴影不是"同一个颜色调暗"——现实里阴影由天光照亮，所以要往蓝紫偏；高光由暖色主光照亮，要往黄偏。每条色阶（ramp）沿明度轴旋转色相，暗端朝 250°、亮端朝 48° 走最短弧。这是暗部不发闷、发灰的唯一原因。5 档一条，index 0 是阴影/描边色，2 是本色，4 是高光。

**2. 封闭调色板。** 连续插值会凭空造出上百个几乎相同的颜色，在 1px 尺度上只会糊成一片而不是细节。`bakeSheet()` 里对每一帧调用 `quantize()`，把像素吸附回调色板——不管绘制过程怎么混色，最终上屏的精灵只用得到调色板里的颜色。`shade(c, t)` 也被改成**沿该颜色自己的色阶走档**，而不是往黑白衰减，所以所有旧的调用点自动变得色阶正确。

**3. 选择性描边（sel-out）。** 统一的纯黑描边会把精灵压平，整套素材看起来像盖章盖出来的。`selOutline()` 让描边**取相邻像素的色相**再沿色阶压暗，并且朝向主光（左上）的边用更浅的描边、背光（右下）的边用更深的——描边本身就在表达形体。

**4. 纹理是"簇"，不是噪点。** 逐像素随机 = 电视雪花。地面用 2–3px 的重复图案（`GRASS_MOTIFS` 等）撒在**抖动过的格点**上，格子永远大于图案，所以簇之间不会连成一片；密度由低频噪声调制，于是有茂密处也有裸露处——留白和细节一样重要。

**5. 平面 + 过渡处抖动。** 全屏 Bayer 抖动会变成一层纱窗纹理。`rampBand()` 让色阶保持成**平坦色块**，只在两档交界的窄带里抖动。

**6. 单一光源方向，不做 pillow shading。** 叶簇、灌木的亮部只画在左上半边，绝不沿轮廓一圈内缩——后者会让物体看起来像个模糊的枕头。

**7. 地面明度压在道具之下。** 广场石板只用色阶的下半段：地面是画面上最大的一块面，如果和道具一样亮，站在上面的东西就没有剪影了。俯视图里规则的错缝砖块会读成"墙"，所以石板的行高、列宽、切角都是随机的。

**8. 小于约 12px 的东西必须手画。** 椭圆生成的药水瓶就是一坨有颜色的团块。药水、金币、钥匙、宝石、心、弹药箱、卷轴、蘑菇、花，以及**人物的头**，全部是用 `parseArt()` 逐像素排版的位图（`POTION_ART` / `HEAD_DOWN` 之类）。位图里只描述形体，描边交给 `selOutline()` 后加。

**9. 圆要按像素画法光栅化。** 用像素**角点**去测 `(dx/r)²+(dy/r)² <= 1`，圆的顶端会收成 1px 尖，这就是所有程序化团块毛糙的根源。改成测**像素中心**、半径外扩半格之后，r=4 的圆行宽正好是 5-7-9-9-9-9-9-7-5——手画圆的标准行程。这一行改动同时修好了工程里每一个圆、椭圆、石头、脑袋、蘑菇伞。

**10. 需要精确形状的地方用行宽表，不用光栅化。** 旋转的金币是一张 `COIN_ROWS = [4,6,8,8,8,8,6,4]` 的行宽表按帧压缩出来的——在这个尺寸上，"手挑的行程序列"就是金币和一坨橙色污渍的全部差别。

**11. 石头是"面"，不是"团"。** 旧版把半透明椭圆叠起来再撒噪点，得到一摊灰色水渍：没有剪影，没有体积。现在是底宽顶窄的硬边剪影 + 一条直的转折线分出受光顶面、正面和背光底面，加一条**直**裂缝——石头之所以像石头，靠的是平面而不是渐变。

**12. 人物的手是 2x2 实块，腿之间留 1px 暗缝。** 混色画出来的手在这个尺寸上只会变成一个杂色点；正面视角两条腿不分缝就会糊成一条裤子。

**13. 走路循环的关键是节奏，不是幅度。** 一个走路循环里有两次**着地**（腿张到最大、身体最低）和两次**过渡**（双腿并拢、身体最高），所以上下起伏的频率是腿摆动的**两倍**，且相位相反。第一版写成 `bob = -|sin|` 配 `legX = sin`，等于腿张最大时身体升到最高——角色看起来是"往前扑的时候向上飘"，这就是它发飘的原因。另外头和衣摆比髋部**滞后**约 0.12 个周期，才有跟随惯性。

**14. 屋顶不能是矩形。** 3/4 俯视下看到的坡屋顶是一个**梯形**：檐口宽、屋脊窄，两条斜边上有封檐板，屋脊上方还露出后坡的两三个像素。第一版把屋顶画成矩形，这就是所有房子读成"方块盒"的全部原因。再加上二层**出挑**（jetty，露出楼板梁头）、侧面**披屋**、屋顶**老虎窗**、窗户**百叶+花箱**、门头雨篷和墙角爬藤，房子才有体积和层次。

**15. 水面不是渐变，是散落的笔画。** 第一版用一个全局正弦场驱动整个水面，出来是平滑的同心等高线——像等高线地形图而不是水。现在是几层**滚动的短横线**（不同速度产生视差）撒在两三档平色之上，加上岸边的花边浪花、岸影、石头后的 V 形尾迹。另外滚动速度**只能是时间的函数**：让它随 x 变化会把水平的笔画剪切成斜线，水面看起来像被叉子刮过。

> 开 `/proof.html` 可以看到所有素材 8 倍放大 + 像素网格 + 锚点十字线。像素画只能在像素级别判断——毛刺、断线、孤立杂点在 1:1 下完全看不出来，8:1 下一目了然。`?g=hero` / `?g=items` / `?g=props` / `?g=town` / `?g=animals` / `?g=fish` 切换分组。

## 玩法循环

| 步骤 | 怎么做 |
| --- | --- |
| 开荒 | 拿**锄头**（1）对着自家地块的格子按住左键，翻出可种植的土 |
| 播种 | 拿**种子**（6/7），对翻好的土使用，种子消耗一个 |
| 浇水 | 拿**水壶**（2），浇过的土会变深色。**没浇水的作物当晚不生长** |
| 过夜 | 进自家小屋走到床边按 `E` 睡觉，天数 +1，作物长一阶，体力回满，土地变干 |
| 收获 | 作物长到第 4 阶后，用**镰刀**（5）收进背包 |
| 卖钱 | 走到地块门口的**出货箱**按 `E`，一次性卖掉背包里所有农产品 |
| 采集 | **斧头**（3）砍树得木料、**镐**（4）敲石头得石料；野地里的**蘑菇和野花**走近按 `E` 直接采走 |
| 买种子 | 进杂货铺，对着柜台后的 MARA 按 `E` 开店：`W`/`S` 选、`E` 买、`Tab` 或 `Esc` 关 |
| 钓鱼 | 拿**鱼竿**（6）面朝河水按空格抛竿，浮标沉下、冒出红色 `!` 时**再按一次**中钩，然后进入收线小游戏 |

三种作物：萝卜（1 天一阶，35G）、南瓜（2 天一阶，90G）、小麦（1 天一阶，25G）。
体力条在右下角，每次使用工具消耗一点，睡觉回满。

**经济是闭环的**：种子花钱买，作物卖的钱比种子贵，所以钱会滚起来而不是一开始给的那点用完就断。
杂货铺卖萝卜种子 12G、小麦种子 9G、南瓜种子 40G——南瓜最贵也最赚，是中期目标。
采来的蘑菇（18G）和野花（14G）既能卖，也是 MARA、SENNA、TESSA、PETH 喜欢的礼物；采过的地方**三天后重新长出来**。

## 钓鱼

抛竿 → 等待 → 中钩 → 收线。等待时间是随机的、跳不过去的；**技术含量全在收线**上：

按住空格让绿色捕捉框往上升，松开它就往下掉（带阻尼，所以是可控的漂浮而不是打滑的冰块）。
鱼在同一根竖轨上乱窜，**只有框套住鱼的时候进度条才涨**，套不住就掉。
大约 35% 的命中率打平，50% 左右五秒能拉上来——越稀有的鱼窜得越凶、捕捉框越小。

**在哪儿钓也算数**：普通河段只有鲤鱼、鲫鱼、鲈鱼这些（12G–75G）；
**磨坊下游的深水潭**另有一张表，梭子鱼、鳗鱼，以及 900G 的**河王**。
抛竿会落在你瞄准方向上那段水面的**中点**，所以站在岸边也够得着河心——这是深潭能玩起来的前提。

这条线是接着 WICK 的：他三档对白里说"磨坊过去的深潭里有东西在拽我的线"，
告示板上的第四个任务就是让你去把它钓上来。鱼可以卖、可以当礼物（WICK 最喜欢）。

## 人与故事

镇上有 **8 位有名有姓的居民**（`src/game/social.ts`）：杂货铺的 MARA、铁匠 BRANN、磨坊主 HALDER、农妇 SENNA、旅店老板 ORIN、渔夫 WICK、牧人 TESSA，以及从海边走来的流浪者 PETH。每个人有自己的工作地点、作息、喜欢的物品，和**随好感度变化的三档对白**。

- `E` 和他们说话，每天第一次交谈 +4 好感
- 手上拿着农产品时 `E` 是**送礼**：送对方喜欢的东西 +25，其他 +8，每人每天一次
- 好感度以爱心显示在对话框标题里，满 2 颗解锁第二档对白，满 4 颗解锁第三档

广场上有一块**告示板**：按 `E` 接任务，凑齐材料后再按 `E` 交任务，拿钱和好感。四个任务按顺序解锁，串起一条线——从"这块荒地还能不能长东西"到"给全谷办一场丰收宴"。当前任务和进度显示在左上角。

## 建筑内部

所有主要建筑都能进：走进门口触发淡入，室内是一个独立的小房间——自己的地板/墙面材质、家具、灯光和 NPC。每间房都有身份和生活痕迹：酒馆有吧台酒瓶架、挂锅、桌上的杯盘和炉边柴堆；杂货铺柜台上摆着天平和账本；铁匠铺有淬火桶、煤堆和墙上的工具排；教堂有彩窗投光、讲台和带靠背的长椅；磨坊有会转的磨盘和面粉溜槽；谷仓里养着牲畜；民房桌上有碗和面包、床边有小地毯。地板带动线磨损和炉前烟渍。走回门口的地垫即可出来。

室内用固定环境光而不是昼夜循环，摄像机在房间比视口小时会**居中**而不是贴边。

**有名字的人就在他自己的店里**：柜台后的杂货铺老板就是 MARA 本人，铁匠铺里的是 BRANN，磨坊里的是 HALDER，酒馆和旅馆里的是 ORIN——好感、送礼、对白在室内一样生效。
他们上工期间**不会同时出现在街上**（否则一个人会出现在两个地方）；傍晚下工后又都回到广场上聚着。
对话判定半径放宽到 44px，否则柜台本身的碰撞体会把你挡在能说话的距离之外，店主永远搭不上话。

## 素材测试内容

### 1. 像素人物

`src/art/character.ts` 用一套**参数化骨架**（髋、肩、头、双臂、双腿）绘制，每个动画只是"每帧返回一个 Pose"的函数，因此 5 套动作 × 3 个朝向（下 / 侧 / 上，左朝向镜像）共 99 帧全部由同一段绘制代码产出，风格不会跑偏。

- `idle` 4 帧呼吸、`walk` 8 帧、`run` 8 帧（加大摆幅 + 前倾 + 扬尘）
- `attack` 6 帧（蓄力 → 突刺 → 收招，非循环）
- `death` 8 帧：先插值成瘫倒姿势，再整体旋转/压扁（`blitTransformed`），同时血泊扩散
- 换一组 `Skin` 参数即可得到第二个角色（仓库里的 `ROGUE_SKIN` 是带兜帽和披风的盗贼）
- 枪是**独立精灵**，绕手部枢轴旋转指向鼠标，所以不需要为每个瞄准角度烘焙额外帧

`src/art/creatures.ts` 里的史莱姆用纯挤压拉伸（squash & stretch）实现 idle/move/attack/death，用来证明动画管线不绑定人形骨架。场景里的史莱姆会游荡、追人、被子弹打死后重生。

### 3. 像素光照

`src/game/lighting.ts`：场景先按全亮渲染，然后叠一张光照贴图。

- 环境光按昼夜曲线插值（`SKY`），一天 150 秒；`[` `]` 可手动拖时间
- 每个光源是**阶梯式径向渐变**（默认 7 档硬边），衰减会分层——这是刻意做的复古质感，而不是柔和的高斯光晕
- 光照贴图以 `multiply` 合成，再对亮核做一次 `lighter` 辉光（越黑辉光越强）
- 支持闪烁（火把用双频噪声）、脉冲（水晶/魔法）、锥形光
- 玩家自带提灯光源；开枪瞬间会有一帧强烈的枪焰照明；子弹自身也是移动光源

### 4. 河流

`src/game/water.ts`：水面每帧**逐像素**渲染（只算可视窗口内的 448×252），而不是贴图循环滚动，因此水流能跟着河岸弯曲、在岸边生成蕾丝状浪花、在石头后方裂开尾迹。

- 河道形状由 `riverSDF()`（到河心线的有符号距离）唯一定义，水面渲染、沙岸烘焙、碰撞判定共用它，美术和玩法不可能对不上
- 水面 = 两三档**平色**（只在交界处抖动）+ 三层**滚动的短横线**。每层有自己的行距、格宽、速度和明度档：慢而长的暗色浪谷给大结构，中速的亮线是浪峰，快而稀的近白短线是波光。三层速度不同产生视差
- 笔画的位置来自**格点哈希**而不是连续函数，所以每一笔都是独立的、离散的，不会糊成等高线
- 岸边：一条花边状的浪花线（同样是格点抖出来的，不是均匀色带）+ 一档**岸影**（贴岸的水反射的是河岸而不是天空，要压暗一档）
- 石头周围有泡沫环和下游 V 形尾迹；玩家沿水边走会溅起水花，子弹入水会炸出水花
- 浅水半透明，能透出烘焙好的河床；河上有木桥，`onBridge()` 是唯一能过河的地方
