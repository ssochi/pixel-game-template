# Pixel Asset Lab — 2D 俯视角像素游戏素材测试场景

对标《挺进地牢（Enter the Gungeon）》的 2D 俯视角像素风格模板。第一步产物：**一个可交互的素材测试场景**，用来验证角色动画、物件/建筑/植物/石头素材、像素光照和河流表现。

所有美术资源都是**运行时程序化生成**的（`src/art/` 里用代码画像素），仓库中没有任何图片文件。

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 类型检查 + 打包到 dist/
```

## 测试内容

### 1. 像素人物

`src/art/character.ts` 用一套**参数化骨架**（髋、肩、头、双臂、双腿）绘制，每个动画只是"每帧返回一个 Pose"的函数，因此 5 套动作 × 3 个朝向（下 / 侧 / 上，左朝向镜像）共 99 帧全部由同一段绘制代码产出，风格不会跑偏。

- `idle` 4 帧呼吸、`walk` 8 帧、`run` 8 帧（加大摆幅 + 前倾 + 扬尘）
- `attack` 6 帧（蓄力 → 突刺 → 收招，非循环）
- `death` 8 帧：先插值成瘫倒姿势，再整体旋转/压扁（`blitTransformed`），同时血泊扩散
- 换一组 `Skin` 参数即可得到第二个角色（仓库里的 `ROGUE_SKIN` 是带兜帽和披风的盗贼）
- 枪是**独立精灵**，绕手部枢轴旋转指向鼠标，所以不需要为每个瞄准角度烘焙额外帧

`src/art/creatures.ts` 里的史莱姆用纯挤压拉伸（squash & stretch）实现 idle/move/attack/death，用来证明动画管线不绑定人形骨架。场景里的史莱姆会游荡、追人、被子弹打死后重生。

### 2. 物件 / 建筑 / 植物 / 石头

| 类别 | 内容 |
| --- | --- |
| 家具 | 桌、椅、木桶、木箱、书架、地毯、床、木牌、宝箱（4 帧开箱动画）、女巫锅（冒泡动画） |
| 建筑 | 石墙 / 残破石墙、石柱、拱门、栅栏、水井、桥面、桥栏、旗帜（飘动动画） |
| 道具 | 药水 ×3、金币（旋转动画）、钥匙、宝石 ×3、弹药箱、心、卷轴 |
| 植物 | 草丛 ×3、灌木 ×2、花 ×3、芦苇 ×2、睡莲、蘑菇（含发光变体）、橡树 ×2、松树、枯树 |
| 石头 | 三种尺寸 + 长苔变体、水晶簇（脉冲发光）、树桩、倒木 |
| 光源 | 火把、篝火、火盆（火焰逐帧程序生成） |

植物的摇曳用**逐行水平错切**（`sway()`）实现——像素全部留在整数网格上，不会因为旋转产生糊边。

按 `Tab` 打开图鉴可以逐个查看所有素材的动画、尺寸和帧数。

### 3. 像素光照

`src/game/lighting.ts`：场景先按全亮渲染，然后叠一张光照贴图。

- 环境光按昼夜曲线插值（`SKY`），一天 150 秒；`[` `]` 可手动拖时间
- 每个光源是**阶梯式径向渐变**（默认 7 档硬边），衰减会分层——这是刻意做的复古质感，而不是柔和的高斯光晕
- 光照贴图以 `multiply` 合成，再对亮核做一次 `lighter` 辉光（越黑辉光越强）
- 支持闪烁（火把用双频噪声）、脉冲（水晶/魔法）、锥形光
- 玩家自带提灯光源；开枪瞬间会有一帧强烈的枪焰照明；子弹自身也是移动光源

### 4. 河流

`src/game/water.ts`：水面每帧**逐像素**渲染（只算可视窗口内的 448×252），而不是贴图循环滚动，因此水流能跟着河岸弯曲、在岸边生成蕾丝状浪花、在石头后方裂开尾迹。

- 河道形状由 `riverSDF()`（到河心线的有符号距离）唯一定义，水面渲染、沙岸烘焙、碰撞判定共用它，美术和玩法不可能对不上
- 表面亮度先算成一个标量，再**量化到 6 级色阶 + Bayer 4×4 有序抖动**，得到手绘感的色带而非 24 位渐变
- 浅水半透明，能透出烘焙好的河床；深水不透明
- 石头周围有泡沫环和下游 V 形尾迹；玩家沿水边走会溅起水花，子弹入水会炸出水花
- 河上有木桥，`onBridge()` 是唯一能过河的地方

## 代码结构

```
src/
  art/            # 全部美术资源的程序化生成（不含任何图片文件）
    pixel.ts      #   PixelBuffer：逐像素画布 + 胶囊/椭圆/描边/变换 blit
    palette.ts    #   全局统一调色板
    sheet.ts      #   精灵表烘焙 + 动画 Clip
    character.ts  #   人形骨架与 5 套动画
    creatures.ts  #   史莱姆
    nature.ts     #   植物、树、石头、水晶
    props.ts      #   家具、建筑、道具、火焰类光源
    assets.ts     #   一次性烘焙入口 + 图鉴清单
  engine/
    screen.ts     #   固定内部分辨率 448×252 + 整数倍放大 + 摄像机
    input.ts      #   键鼠输入（已换算到内部像素坐标）
    font.ts       #   3×5 位图字体（UI 文字也保持在像素网格上）
    rng.ts        #   确定性随机 + 值噪声 / fbm
  game/
    terrain.ts    #   世界尺寸、河道 SDF、桥、地面位图烘焙
    water.ts      #   河流逐像素渲染
    lighting.ts   #   光照贴图与昼夜循环
    scene.ts      #   场景摆放（建筑/家具/植被/光源/碰撞）
    player.ts     #   可操控角色、射击、子弹
    agents.ts     #   史莱姆 AI
    particles.ts  #   尘土、水花、火星、血、余烬
    ui.ts         #   HUD、帮助面板、素材图鉴
  main.ts         # 启动与主循环
```

渲染顺序：烘焙地面 → 河流 → 平铺装饰（地毯 / 草 / 睡莲 / 桥面）→ Y 轴排序的世界物体 → 粒子与子弹 → 光照合成 → HUD。
