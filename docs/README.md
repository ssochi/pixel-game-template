# docs/ — 里程碑工作区

这个目录是《河谷小镇》的开发档案。它不是给玩家看的说明书（那是根目录的 `README.md`），
而是**规划与验收的记录**：每个里程碑要解决什么、怎么判定做完了、做完之后世界变成了什么样。

## 目录

| 文件 | 内容 |
| --- | --- |
| `ROADMAP.md` | 蓝图。当前这一轮 10 个里程碑的排序与理由 |
| `PROCESS.md` | 里程碑的工作方式：怎么开、怎么迭代、怎么算完成 |
| `milestones/M00-exploration.md` | **探索里程碑**：现状勘察报告与缺陷清单 |
| `milestones/M01-*.md` … | 各执行里程碑的任务书与验收记录 |

## 大循环

```
M00 探索  →  M01 … M10 执行  →  M11 探索  →  M12 … M21 执行  →  …
```

每完成 10 个执行里程碑，重新开一次探索里程碑：重新勘察代码、重新看画面、
重新收集外部参考，然后**推翻并重写蓝图**。旧蓝图不延续——十个里程碑之后，
游戏已经不是当初那个游戏了，按老地图走会走错方向。

## 不变的约束

这些在任何里程碑里都不会被放宽（同 `CLAUDE.md`）：

- 内部分辨率 **448×252**，整数倍放大
- **零二进制资源**：美术全部是 `src/art/` 里的程序化生成代码，仓库里没有图片、没有音频文件
- 颜色只能来自 `src/art/palette.ts` 的色阶
- **不新增运行时依赖**
- 提交前 `npx tsc --noEmit` 与 `npx vite build` 必须过
