# 蓝图 — 第一轮（M01 – M10）

由 `milestones/M00-exploration.md` 的勘察结论推出。**M11 会是下一个探索里程碑，
届时这份蓝图作废重写。**

## 排序的理由

三条原则决定了下面的顺序：

1. **先修坏的，再补缺的。** 一个纯黑色的村民让人觉得游戏是坏的；没有矿洞只让人觉得游戏小。
   坏的东西损害信任，缺的东西只是限制上限。
2. **存档在所有内容之前。** 在进度能被保存之前，做出来的每一份内容都是一次性的。
3. **每加一个系统，必须往两个已有系统里回流。** 并联的系统只是清单，串联的系统才是游戏。

## 里程碑

### M01 — 缺陷清扫：让它不像是坏的
把 M00 第二节 A–J 全部修掉。纯黑村民、洋红地毯与床、通铺地板、搁板长椅、
水里的放大镜、空草坪农场、Gungeon 残留、HUD 默认状态、室内黑边。
**这一批做完，游戏的第一印象从"有 bug 的 demo"变成"一个小而完整的镇子"。**

### M02 — 存档
`localStorage` 序列化：天数、时刻、农田每一格、背包、金钱、好感度、任务链、采集点重生计时。
睡觉时自动存档，启动时有"继续 / 新游戏"。版本号 + 迁移兜底，改了存档结构不会让老档崩掉。
**回流**：让 M03 以后的一切内容都能积累。

### M03 — 四季与天气
一季 28 天，四季轮转。地面/树木色阶随季节换档（对程序化美术来说，换季 = 换一档色阶，
不需要重画素材）。作物有季节窗口，过季枯死。雨天自动浇水、雷雨、冬雪封田。
**回流**：给种田加窗口期压力；给钓鱼加季节鱼表；给好感加"生日"的容器。

### M04 — 真正的背包
30 格背包面板，与快捷栏分离。堆叠、拖拽、丢弃、物品说明。卖东西走店内界面而不是出货箱一键清仓。
**回流**：矿洞、烹饪、制作全都需要格子，这是它们的前置。

### M05 — 矿洞
程序生成的多层洞穴，梯子下探，铜/铁/金矿脉与宝石，怪物（复用史莱姆骨架与 `agents.ts`，
让 M01 删掉的战斗代码在它该在的地方复活）。矿石 → 工具升级（锄头/水壶/斧头分级）。
**回流**：镐子终于有纵深；工具升级直接放大种田效率。

### M06 — 制作与烹饪
工作台配方（箱子、洒水器、稻草人、地板）、厨房料理（吃了给移动速度 / 体力 / 钓鱼加成）。
洒水器自动浇水 = 农场规模可以扩大。
**回流**：把木料/石料/矿石/作物/鱼**全部**接进一个出口；把"赚到 5000G 之后没东西可买"这个洞填上。

### M07 — 音效与音乐
WebAudio 程序化合成，**不加任何音频文件**（和"零二进制资源"的约束一致）。
锄地、浇水、收获、开门、脚步、水声、店铺提示音；按季节切换的环境底噪与简单旋律。
**回流**：反馈层。所有已有动作立刻变得"有手感"。

### M08 — 节日与心动事件
每季一个广场节日（春花祭、夏夜灯会、秋收宴、冬日集市），有专属布景、玩法小游戏和奖品。
好感度到达 4/6/8 颗心触发角色专属事件。
**回流**：给好感度一个终点；给季节一个记忆点。

### M09 — 世界密度与地貌
修 M00 第二节 H：草地的斑块换成有形状的裸土与簇状植被；道路给出明确边沿与车辙；
芦苇/灌木随机化。扩地图：山道通矿洞、下游沙滩、镇北墓园。地标要能当路标用。
**回流**：让 M05 的矿洞和 M08 的节日有地方发生。

### M10 — 打磨与收尾
小地图、开局引导、暂停菜单、性能盘点（烘焙时间与逐像素水面的开销）、
键位可视化、根目录 README 全面重写。这一轮的结案。

### M11 — 探索里程碑（下一轮的起点）
重新勘察、重新截图、重新查外部参考，**重写蓝图**。
